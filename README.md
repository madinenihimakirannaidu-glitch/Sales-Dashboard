# Sales & Revenue Analysis Dashboard

## Objective
Analyze sales performance and revenue trends using an interactive dashboard.

## Features
- Revenue Trend Analysis
- Sales by Product Category
- Top Performing Products
- Revenue by Region
- Payment Method Analysis
- Interactive Filters

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit

## Dataset
Online Sales Data Dataset

## Output
Interactive dashboard displaying sales KPIs and business insights.

## Files
- app.py
- Online Sales Data.csv
- requirements.txt
